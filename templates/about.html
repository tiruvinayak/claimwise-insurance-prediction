ABOUT CLAIMWISE

Understanding Insurance Claims Through Machine Learning

A systematic data engineering and predictive modeling project for insurance claim analytics.

Project Overview

ClaimWise Insurance Prediction System is an academic machine learning project designed to process historical insurance claim datasets, execute systematic feature engineering, and estimate claim loss values using regression models.

Problem Statement

Insurance companies process vast quantities of customer, policy, and claim records daily. Manual claim loss assessment is labor-intensive and slow. Machine learning algorithms analyze historical patterns in complex claim data to provide rapid, data-driven estimations of claim loss.

What Does loss Mean?

loss is a continuous claim-severity value from the Allstate Claims Severity dataset. On this 50,000-row production subset it ranges from 10.00 to 85,923.56 with a median of about 2,119. The distribution is strongly right-skewed (skewness ≈ 3.86): most claims are small, while a thin tail of very large claims dominates the variance.

The dataset schema does not define currency units, and the anonymized feature names (cat1–cat116, cont1–cont14) carry no documented business meanings. ClaimWise never invents interpretations for them.

Objectives

  • Incorporate 50,000 historical insurance records for empirical analysis.
  • Clean raw dataset by removing redundant identifiers and handling missing values.
  • Encode categorical text attributes into numerical representations.
  • Standardize continuous numerical attributes for balanced model learning.
  • Split preprocessed dataset into 40,000 training and 10,000 testing subsets; carve a 7,500-row validation set from training for model selection.
  • Prepare features for regression-based claim loss prediction.

Data Preparation & Preprocessing

The single authoritative pipeline (Src/claimwise_preprocessing_pipeline.py) removes the identifier column id, deduplicates rows, imputes missing continuous values with training medians and missing categorical values with modes, label-encodes the 116 categorical features, and standardizes the 14 continuous features with a StandardScaler fitted only on the 40,000 training rows. The raw dataset is preserved untouched; intermediate stages are written to numbered CSVs under Dataset/.

Machine Learning Approach

ClaimWise treats claim loss prediction as a continuous regression task. Models are trained on preprocessed predictor matrices containing 130 features to predict the continuous target variable loss.

Sixteen model families are benchmarked (Dummy baseline, Linear/Ridge/Lasso/Elastic Net, Linear SVR, Decision Tree, Random Forest, Extra Trees, Gradient Boosting, Hist Gradient Boosting, AdaBoost, K-Nearest Neighbors, XGBoost, CatBoost and log1p-target variants). A 7,500-row validation set carved from training (seed 2026, stratified by loss decile) selects the champion by lowest validation MAE; the winner is then refitted on all 40,000 train+validation rows and evaluated exactly once on the untouched 10,000-row holdout. Current production result: holdout MAE $1,154.95, RMSE $2,001.08, R² 0.5396 — an honest figure, not a 0.95 claim. A separate high-loss triage classifier is reported in its own section and its F1 does not measure regression accuracy.

Purpose & Responsible Use

  • This is an academic analytics demonstration, not an insurance approval engine, fraud detector, or guaranteed payout calculator.
  • A predicted loss is a statistical estimate of expected claim severity — not a settlement, quote, or legal offer.
  • Model performance is limited by anonymized features and heavy target skew; treat outputs as decision-support context only.
  • No customer-identifiable data is used; the dataset is fully anonymized.

Technology Stack

  • Python — Core pipeline scripting
  • Pandas & NumPy — Data manipulation & arrays
  • Scikit-Learn — Preprocessing & regression models
  • Flask & HTML5/CSS — Web application framework

Why ClaimWise?

ClaimWise demonstrates how an automated data preprocessing pipeline converts raw, high-dimensional insurance records into clean, standardized matrices ready for regression modeling — with leakage-safe evaluation and honest reporting of results.
