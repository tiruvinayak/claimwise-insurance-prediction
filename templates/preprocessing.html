PREPROCESSING SAFEGUARD

Data Leakage Prevention

StandardScaler is fitted only on the training data to prevent information from the test set from influencing preprocessing. The scaler learns its parameters from the training data only. The same fitted scaler is then applied to the test data.

Training continuous-feature mean {{ '%.6f'|format(leakage['train_max_abs_mean']) if leakage['available'] else '—' }} Scaler fitted on these rows
Testing continuous-feature mean {{ '%.6f'|format(leakage['test_max_abs_mean']) if leakage['available'] else '—' }} Transformed with the fitted scaler only
Scaled continuous features {{ leakage['continuous_count'] if leakage['available'] else '—' }} cont1 – cont14

Both figures are the largest absolute mean across the scaled continuous features, verified in 02_ClaimWise_Data_Preprocessing.ipynb. The training value is 0.000000 because the scaler was fitted on those rows; the test value is not zero because test rows only inherit the transformation. The key point is that the scaler was never fitted on the test data. Read the full explanation in the Data Leakage Prevention section.
