Explicit Workflow for Training on a New Dataset

Uploading a dataset never automatically retrains the saved production model. Automatic retraining on arbitrary uploads is unsafe. To train models on a new dataset, execute the dedicated pipeline workflow:

  1. Data Health Validation: Audit missing cells, remove duplicate rows, and inspect class frequencies.
  2. Feature Preprocessing: Fit LabelEncoders for categorical columns and StandardScaler for continuous variables exclusively within training splits.
  3. Partitioning: Split the cleaned data into 80% train and 20% test splits using fixed random seed (42).
  4. Model Training & CV: Fit all candidate algorithms (Linear Regression, Decision Tree, Random Forest, Gradient Boosting, Hist Gradient Boosting) with cross-validation.
  5. Evaluation & Verification: Measure MAE, MSE, RMSE, and R² on held-out test data. Confirm tie-breakers before declaring best model.
  6. Artifact Preservation: Save updated model pickle files into Models/ and metrics to Outputs/.

Script reference: Src/claimwise_preprocessing_pipeline.py & Src/train_models.py.
